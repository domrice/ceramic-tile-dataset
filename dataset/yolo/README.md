# YOLO Training for Tile Detection

This directory contains a YOLO training pipeline for tile detection.

## Files

- `train.py` - Main training script
- `test.py` - Testing and inference script  
- `data_utils.py` - Data preparation utilities
- `dataset/` - Directory for training data

## Setup

1. **Create a virtual environment:**
   ```bash
   conda create -n yolo python=3.10
   conda activate yolo
   ```

2. **Install dependencies:**
   ```bash
   cd src/yolo
   uv sync --group capture
   ```

3. **Prepare your dataset:**
   - Place your images and labels in appropriate directories
   - Use the data utilities to split your dataset:
   ```bash
   python data_utils.py split --images /dataset/raw/images --labels /dataset/raw/labels --output dataset
   ```

4. **Create classes file:**
   ```bash
   python data_utils.py classes --names tile --output dataset/classes.txt
   ```

5. **Validate dataset:**
   ```bash
   python data_utils.py validate --dataset dataset
   ```

## Training

### Basic Training
```bash
python train.py --dataset dataset
```

### Advanced Training
```bash
python train.py --dataset dataset --model yolo11l.pt --epochs 200 --batch-size 16 --img-size 1280 --device 0 --output-name tile_detection_model
```

### Training Parameters
- `--dataset`: Path to dataset directory (default: "dataset")
- `--model`: YOLO model to use (yolo11n.pt, yolo11s.pt, yolo11m.pt, yolo11l.pt, yolo11x.pt)
- `--epochs`: Number of training epochs (default: 60)
- `--img-size`: Image size for training (default: 640)
- `--device`: Device to use (auto/cpu/cuda/0/1/etc.)
- `--output-name`: Name for output model (default: "tile_detection_model")

## Testing

### Test on Images

```bash
python test.py --model models/tile_detection_model.pt --images test_images/
```

### Evaluate on Dataset

```bash
python test.py --model models/tile_detection_model.pt --dataset dataset/data.yaml
```


## Dataset Structure

Your dataset should be organized as follows:
```
dataset/
├── classes.txt          # Class names, one per line
├── data.yaml            # Auto-generated by train.py
├── train/
│   ├── images/          # Training images
│   └── labels/          # Training labels (YOLO format)
└── validation/
    ├── images/          # Validation images
    └── labels/          # Validation labels (YOLO format)
```

## Label Format

Labels should be in YOLO format (one .txt file per image):
```
class_id center_x center_y width height
```

Where coordinates are normalized to [0,1].

## Output Structure

After training, you'll find:
```
models/
├── tile_detection_model.pt      # Trained model weights
└── training_results/            # Training logs, plots, etc.

runs/detect/train/               # YOLO output directory
└── weights/
    ├── best.pt                  # Best model weights
    └── last.pt                  # Last epoch weights
```

## Tips

1. **GPU Usage**: Make sure you have CUDA installed if using GPU training
2. **Dataset Size**: Larger datasets generally produce better models
3. **Model Selection**: Start with `yolo11s.pt` for fast training, use `yolo11m.pt` or larger for better accuracy
4. **Image Size**: 640 is a good default, use 1280 for higher accuracy (slower training)
5. **Epochs**: Start with 60-100 epochs, monitor validation loss to avoid overfitting

## Troubleshooting

- **Import errors**: Make sure all dependencies are installed (`uv sync --group capture`)
- **CUDA issues**: Check CUDA compatibility with PyTorch version
- **Memory errors**: Reduce batch size or image size
- **No detections**: Check confidence threshold, validate labels format
